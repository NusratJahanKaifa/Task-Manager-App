# Task Manager App

A simple, responsive task manager for adding, completing and deleting daily tasks. Tasks are saved in the browser, so they stay after a page refresh.

**Live Demo:** [View Project](https://nusratjahankaifa.github.io/Task-Manager-App/)

## Features

- Add new tasks (with the Add Task button or the Enter key)
- Mark tasks as completed with a checkbox
- Delete tasks you no longer need
- Each task shows the date it was created, and a counter shows the total number of tasks
- Tasks are saved with localStorage, so they persist after reloading the page
- Responsive layout that works on desktop and mobile

## Tech Stack

HTML5, CSS3, JavaScript (localStorage)

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/NusratJahanKaifa/Task-Manager-App.git
   ```
2. Open `index.html` in your browser.

No installation is needed.
